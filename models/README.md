# RoadGuard Model Directory

Place your fine-tuned `best.pt` or `yolov8n-seg.pt` weights here:
```
models/
└── best.pt
```

> **Note:** If no weights file is present, RoadGuard automatically activates its built-in Computer Vision Feature-Based Heuristic Engine (combining CLAHE, morphological gradient filtering, and Non-Maximum Suppression).
